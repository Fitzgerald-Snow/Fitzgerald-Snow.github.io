# Botao Zhang

Personal homepage: https://fitzgerald-snow.github.io/

The site is static HTML, CSS and JavaScript, published by GitHub Pages from the root of `master`. Page text and links are stored in `content.js`. The local draft editor updates that file; publishing changes requires committing and pushing it to this repository.

The homepage links to `research.html` for project details and research interests. Each research project and interest can have an optional `details` field, shown only on the Research page; when blank, that page uses its existing `description`.
